# NEXORA

NEXORA is a secure, network-aware game discovery and deal intelligence platform designed for PC gamers.

The project focuses on game discovery, deals, giveaways, wishlists, alerts, API integration, cyber-security controls, Liquid Glass UI design, AI chatbot integration and future cross-platform expansion.

## Project Status

Personal learning project now. Future final-year project and research preparation later.

## Main Focus Areas

- Game discovery
- Deal and giveaway tracking
- Wishlist and alerts
- Secure authentication
- API integration
- Network-aware architecture
- Cyber-security enhancement
- Liquid Glass UI design
- AI chatbot integration
- Future Android, iOS, Windows and macOS support

## Current Development Plan

Phase 1: Web-first MVP.

## Main Folders

- `docs/` - Project documentation
- `frontend/` - Web frontend application
- `backend/` - Backend API application
- `database/` - Database schema, migrations and seed data
- `assets/` - Logo, images and UI references
- `devops/` - Docker, deployment and CI/CD files
- `research/` - Research notes and final-year project preparation
