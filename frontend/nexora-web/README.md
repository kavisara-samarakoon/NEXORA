# Archived NEXORA Vite prototype

**Status: archived and frozen.** `frontend/nexora-web` is the legacy Vite
prototype, retained for historical reference only.

The canonical active frontend is **`frontend/nexora-web-next`**. Follow its
[README](../nexora-web-next/README.md) for setup, development, linting, and builds.

- **Do not deploy `frontend/nexora-web`.** The deployment target is the Next.js
  frontend only; use `frontend/nexora-web-next` as the Vercel project root.
- **Do not use this directory for new feature work.** Make active frontend
  changes in `frontend/nexora-web-next`.
- Source code, assets, and existing package/build files remain in place to
  preserve the prototype. Their presence does not make this an active or
  supported deployment target.

See the [frontend directory guide](../README.md) for the active/archive boundary.
